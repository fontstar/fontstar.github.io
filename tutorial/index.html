--- --- Tutorial - FontStar

Extension Tutorial

Before we get started, please make sure you're in Safari, not some other browsers like Chrome or Firefox. Thanks!

1
In the address bar, tap any of these icons: 🔲 🧩 📱 AA. Then Select "Manage Extensions 🧩".
If you're using Mac, go to Safari > Settings > Extensions.
2
Find "FontStar"; switch it on, then tap "Done" or the check mark icon ☑️.
On Mac, just close the Settings window.
3
Tap "FontStar" again to allow access.
On Mac, FontStar should appear in your Safari toolbar.
4
Choose "Always allow..." to open more settings.
FontStar never collects your data. Choose "Always Allow..." for the smoothest experience, or "Allow for One Day" if you prefer to decide each time.
5
Choose "Always Allow on Every Website".
FontStar never tracks your history or collects data. Apple's alert appears for all extensions — we only use the permission to change fonts. You can also choose "Always Allow on This Website" and decide for others later. 👉 Check our FAQ for more info.
